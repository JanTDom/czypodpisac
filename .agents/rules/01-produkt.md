# Reguły produktu
- Główna ścieżka: maks. 3 kroki — wgraj → odpowiedz na ≤3 pytania → raport.
- Darmowy poziom: werdykt + 3 najpoważniejsze ryzyka. Płatny: pełny raport, poprawki, mail, eksport DOCX ze śledzeniem zmian i PDF. Dopłata: konsultacja z prawnikiem.
- Płatność domyślnie za dokument. Abonament tylko dla firm.
- Raport: werdykt → czerwone → żółte → braki → zielone.
- Każdy punkt: tytuł po ludzku → cytat z umowy (podświetlony) → co to znaczy dla użytkownika → kwota ryzyka (jeśli policzalna) → źródło → proponowana zmiana.
- Pytania kontekstowe zależą od typu umowy (strona umowy, kwota, termin podpisu, status konsumenta lub przedsiębiorcy na prawach konsumenta).
- Nie pokazuj pewności, której system nie ma. Poziom pewności widoczny przy uwagach interpretacyjnych.
- Każda funkcja ma metrykę: konwersja free→paid, czas do raportu, odsetek eskalacji, ocena użyteczności raportu (1–5).
