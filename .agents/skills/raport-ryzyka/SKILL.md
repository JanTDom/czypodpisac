# Struktura
1. Werdykt (jedno zdanie) + liczba uwag czerwonych/żółtych + łączna kwota ryzyka (jeśli policzalna).
2. Czerwone → żółte → braki → zielone (zwinięte).
3. Uwaga: tytuł po ludzku; cytat; „Co to dla ciebie znaczy”; kwota i założenia; źródło z datą stanu prawnego; proponowana zmiana; pewność.
4. „Co zrobić teraz”: negocjuj / poproś o zmiany / skonsultuj z prawnikiem / możesz podpisać.
5. Stopka: oznaczenie treści AI, data analizy, wersja bazy prawnej.
# Pisanie
- Zdania do 20 słów, strona czynna, druga osoba.
- Kwota zawsze z założeniem („przy czynszu 3000 zł i 3 miesiącach…”).
- Skala ryzyka wynika z faktów, nie z przymiotników.
